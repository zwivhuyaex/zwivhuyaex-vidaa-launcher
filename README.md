# Zwivhuyaex Cinematic — VIDAA HTML5 prototype

A static browser prototype for testing a custom entertainment interface on a Toshiba VIDAA TV.

## Live preview
Once GitHub Pages is enabled, open the published Pages URL on the TV using its built-in browser.

## Controls
- Arrow keys: move between tiles
- Enter / OK: select a tile
- Escape / Backspace: close the information panel
- Settings tile: preview wallpaper mood controls

## Important limitations
This is a web application, not an installable VIDAA package and not a replacement for the VIDAA system launcher. The streaming-service tiles are illustrative only and do not launch installed TV apps. Weather is a placeholder. Real VIDAA integrations require supported system APIs and an approved development/deployment route for the exact TV firmware.

## Hosting
This repository is intended for GitHub Pages static hosting. In the repository settings, enable Pages and select **Deploy from a branch**, branch **main**, folder **/(root)**.
